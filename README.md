# GetLivedIn

## Find a home, not just a house.

GetLivedIn is a Canadian home intelligence platform that reveals:

- What living there actually feels like
- The true cost of ownership
- How to win the offer

## Technology

- Next.js
- Cloudflare Pages
- Cloudflare Workers
- Cloudflare D1
- Cloudflare R2
- OpenAI
- Stripe
